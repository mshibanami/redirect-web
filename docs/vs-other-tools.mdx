# Comparison with Other Tools

Several tools overlap with RedirectWeb. It is meant to work alongside them, and this page compares it with each one.

> [!NOTE]
> These comparisons are based on the state as of October 2025. Please [contact us](/contact-us) if you find any outdated information or mistakes. Thank you! 🙏

## [Redirector](https://github.com/einaregilsson/Redirector) {/* #redirector */}

Redirector is a great browser extension for redirection. It's completely free and open source, and it works on non-Apple platforms, too. But RedirectWeb has some extra features you might like:

- Rules can have multiple exclude patterns and multiple process matches, and the string replacement features are available only in RedirectWeb.
- On Mac, you can choose which native app opens the target URL. RedirectWeb calls the `open` command directly (not deep linking).
- It supports [DNR](https://blog.mozilla.org/addons/2023/05/17/declarativenetrequest-available-in-firefox/), which makes redirection faster.
- You manage the rules for all browsers in one place, the native app.
- It uses Manifest V3 on Chromium-based browsers and V2 on Firefox, where it can use the same API as Redirector.
- It supports Safari on iOS and macOS. Redirector does not.

We highly respect Redirector, and RedirectWeb can import and export redirection rules in a format Redirector also handles, so you can switch between the two. See [Export or import rules](/export-or-import-rules) for details.

## Userscript managers like [Tampermonkey](https://www.tampermonkey.net/) or [Greasemonkey](https://www.greasespot.net/) {/* #userscript-managers */}

Userscript managers are very powerful and flexible. You can do so many things with them, including redirection. However, they have some drawbacks compared to RedirectWeb:

- Writing and maintaining scripts takes time, especially if you are not familiar with programming. RedirectWeb lets you create and manage rules without coding.
- Scripts might add performance overhead, especially if they are complex or not optimized, and a carelessly written one may cause an infinite redirect loop. RedirectWeb is designed to be efficient and safe.
- Some userscript managers may not have access to the Declarative Net Request (DNR) API, which can redirect faster and more efficiently. RedirectWeb supports DNR.

## Apple's [Shortcuts](https://support.apple.com/guide/shortcuts/welcome/ios) {/* #why-not-shortcuts */}

Shortcuts is Apple's automation tool for iOS and macOS. You can create shortcuts for many tasks, including opening URLs. However, you have to trigger a shortcut manually, and Shortcuts is not designed to redirect pages as you browse.

## [OpenIn](https://loshadki.app/openin4/) or [Velja](https://sindresorhus.com/velja) {/* #openin-or-velja */}

OpenIn and Velja are both browser picker apps, and they also have browser extensions that let you open links in another app from a browser. RedirectWeb can redirect from a browser to an app too, but it differs in two ways:

- With OpenIn and Velja, you select their toolbar icon to open a link in another app. RedirectWeb redirects URLs automatically based on your rules.
- OpenIn and Velja are designed for Mac. RedirectWeb supports all major browsers on Mac, and Safari on iPhone, iPad, and Apple Vision Pro.

## [StopTheMadness](https://underpassapp.com/StopTheMadness/) {/* #stopthemadness */}

StopTheMadness is a browser extension with many features for improving web browsing, including redirection. However, it has some limitations compared to RedirectWeb:

- Its rule configuration options are limited. RedirectWeb has more detailed rule settings, including multiple exclude patterns and capturing group processing.
- It includes many features you may not need if you only want redirection. RedirectWeb does redirection only.
- It costs 12-15 USD and has no free trial or free plan. RedirectWeb has a free plan with basic features, a subscription with a free trial of all features, and a one-time purchase option for the price of a coffee.

## Lastly...

These tools are great in their own ways, and one of them might suit you better than RedirectWeb. Use whichever fits best! 😊

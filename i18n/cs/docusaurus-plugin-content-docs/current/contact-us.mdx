# Kontaktujte nás

Jsme tu pro vás, pokud máte jakékoli dotazy, zpětnou vazbu nebo problémy s RedirectWeb, na které jste nenašli odpovědi na stránce [FAQ](/faq).

Zde jsou nejlepší způsoby, jak se s námi spojit:

- **[GitHub Issues](https://github.com/mshibanami/RedirectWeb/issues)**: Pokud narazíte na nějaké chyby nebo chcete požádat o nové funkce, navštivte prosím stránku GitHub Issues. Můžete zde procházet existující problémy, odeslat nový problém a sledovat postup jeho řešení.
- **[GitHub Discussions](https://github.com/mshibanami/RedirectWeb/discussions)**: Pokud máte nějaké dotazy nebo chcete získat pomoc od vývojáře či ostatních uživatelů, navštivte prosím stránku GitHub Discussions. Můžete zahájit novou diskusi, připojit se k existujícím diskusím a získat pomoc od komunity.
- **Formulář pro zpětnou vazbu**: Zpětnou vazbu nám můžete poslat prostřednictvím formuláře přímo v aplikaci RedirectWeb. Ten odešle e-mail přímo vývojáři, takže vaše zpětná vazba zůstane soukromá a nebude viditelná pro ostatní uživatele.

Děkujeme, že používáte RedirectWeb! Vážíme si vaší podpory a zpětné vazby.

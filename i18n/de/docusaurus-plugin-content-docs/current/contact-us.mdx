# Kontakt

Wir helfen Ihnen gerne weiter, wenn Sie Fragen, Feedback oder Probleme mit RedirectWeb haben, für die Sie auf der [FAQ](/faq)-Seite keine Antworten finden konnten.

Hier sind die besten Möglichkeiten, uns zu kontaktieren:

- **[GitHub Issues](https://github.com/mshibanami/RedirectWeb/issues)**: Wenn Sie auf Fehler stoßen oder neue Funktionen anfordern möchten, besuchen Sie bitte die Seite GitHub Issues. Sie können vorhandene Issues durchsuchen, ein neues Issue einreichen und den Fortschritt Ihres Issues verfolgen.
- **[GitHub Discussions](https://github.com/mshibanami/RedirectWeb/discussions)**: Wenn Sie Fragen haben oder Hilfe vom Entwickler oder anderen Benutzern erhalten möchten, besuchen Sie bitte die Seite GitHub Discussions. Sie können eine neue Diskussion starten, an bestehenden Diskussionen teilnehmen und Hilfe von der Community erhalten.
- **Feedback-Formular**: Sie können uns Feedback über das Feedback-Formular in der RedirectWeb-App senden. Dies sendet eine E-Mail direkt an den Entwickler, sodass Ihr Feedback vor anderen Benutzern geheim bleibt.

Vielen Dank, dass Sie RedirectWeb nutzen! Wir schätzen Ihre Unterstützung und Ihr Feedback.

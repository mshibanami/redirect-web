# Contáctanos

Estamos aquí para ayudarte si tienes alguna pregunta, comentario o problema con RedirectWeb para el que no pudiste encontrar respuestas en la página de [Preguntas frecuentes (FAQ)](/faq).

Aquí tienes las mejores formas de ponerte en contacto:

- **[GitHub Issues](https://github.com/mshibanami/RedirectWeb/issues)**: Si encuentras algún error o quieres solicitar nuevas funciones, visita la página de GitHub Issues. Puedes explorar los problemas existentes, enviar un nuevo problema y realizar el seguimiento de su progreso.
- **[GitHub Discussions](https://github.com/mshibanami/RedirectWeb/discussions)**: Si tienes alguna pregunta o quieres obtener ayuda del desarrollador u otros usuarios, visita la página de GitHub Discussions. Puedes iniciar una nueva conversación, unirte a las discusiones existentes y obtener ayuda de la comunidad.
- **Formulario de comentarios**: Puedes enviarnos tus comentarios a través del formulario de comentarios en la aplicación RedirectWeb. Esto enviará un correo electrónico directamente al desarrollador, por lo que tus comentarios se mantendrán privados para otros usuarios.

¡Gracias por usar RedirectWeb! Agradecemos tu apoyo y tus comentarios.

# Nous contacter

Nous sommes là pour vous aider si vous avez des questions, des commentaires ou des problèmes avec RedirectWeb pour lesquels vous n'avez pas trouvé de réponses sur la page [FAQ](/faq).

Voici les meilleurs moyens de nous contacter :

- **[GitHub Issues](https://github.com/mshibanami/RedirectWeb/issues)** : Si vous rencontrez des bugs ou si vous souhaitez demander de nouvelles fonctionnalités, veuillez visiter la page GitHub Issues. Vous pouvez parcourir les problèmes existants, soumettre un nouveau problème et suivre la progression de votre demande.
- **[GitHub Discussions](https://github.com/mshibanami/RedirectWeb/discussions)** : Si vous avez des questions ou si vous souhaitez obtenir de l'aide du développeur ou d'autres utilisateurs, veuillez visiter la page GitHub Discussions. Vous pouvez lancer une nouvelle discussion, rejoindre des discussions existantes et obtenir de l'aide de la communauté.
- **Formulaire de commentaires** : Vous pouvez nous envoyer vos commentaires via le formulaire de commentaires dans l'application RedirectWeb. Cela enverra un e-mail directement au développeur, afin que vos commentaires restent privés vis-à-vis des autres utilisateurs.

Merci d'utiliser RedirectWeb ! Nous apprécions votre soutien et vos commentaires.

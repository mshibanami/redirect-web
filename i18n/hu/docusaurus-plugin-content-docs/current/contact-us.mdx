# Kapcsolatfelvétel

Azért vagyunk itt, hogy segítsünk, ha bármilyen kérdése, visszajelzése vagy problémája van a RedirectWeb-bel kapcsolatban, amelyre nem talált választ a [FAQ](/faq) oldalon.

Itt vannak a legjobb módok a kapcsolatfelvételre:

- **[GitHub Issues](https://github.com/mshibanami/RedirectWeb/issues)**: Ha hibába ütközik, vagy új funkciókat szeretne kérni, látogasson el a GitHub Issues oldalra. Böngészhet a meglévő hibajegyek között, beküldhet újat, és nyomon követheti hibajegye állapotát.
- **[GitHub Discussions](https://github.com/mshibanami/RedirectWeb/discussions)**: Ha kérdése van, vagy segítséget szeretne kérni a fejlesztőtől vagy más felhasználóktól, látogasson el a GitHub Discussions oldalra. Új beszélgetést indíthat, csatlakozhat a meglévőkhöz, és segítséget kaphat a közösségtől.
- **Visszajelzési űrlap**: Visszajelzést küldhet nekünk a RedirectWeb alkalmazásban található visszajelzési űrlapon keresztül. Ez közvetlenül a fejlesztőnek küld egy e-mailt, így visszajelzése privát marad a többi felhasználó előtt.

Köszönjük, hogy a RedirectWeb-et használja! Nagyra értékeljük támogatását és visszajelzését.

# Contattaci

Siamo qui per aiutarti se hai domande, feedback o problemi con RedirectWeb per i quali non hai trovato risposte nella pagina [FAQ](/faq).

Ecco i modi migliori per metterti in contatto:

- **[GitHub Issues](https://github.com/mshibanami/RedirectWeb/issues)**: Se riscontri bug o vuoi richiedere nuove funzionalità, visita la pagina GitHub Issues. Puoi consultare i problemi esistenti, inviarne uno nuovo e seguire l'avanzamento della tua segnalazione.
- **[GitHub Discussions](https://github.com/mshibanami/RedirectWeb/discussions)**: Se hai domande o vuoi ricevere aiuto dallo sviluppatore o da altri utenti, visita la pagina GitHub Discussions. Puoi avviare una nuova discussione, unirti a quelle esistenti e ricevere aiuto dalla community.
- **Modulo di feedback**: Puoi inviarci un feedback tramite il modulo di feedback nell'app RedirectWeb. Questo invierà un'e-mail direttamente allo sviluppatore, quindi il tuo feedback rimarrà privato e non sarà visibile agli altri utenti.

Grazie per aver utilizzato RedirectWeb! Apprezziamo il tuo supporto e il tuo feedback.

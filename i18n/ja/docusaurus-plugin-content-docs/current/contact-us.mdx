# お問い合わせ

RedirectWeb に関するご質問、フィードバック、または不具合があり、[よくある質問 (FAQ)](/faq) ページで解決策が見つからない場合は、こちらからお問い合わせください。

主なお問い合わせ方法は以下の通りです：

- **[GitHub Issues](https://github.com/mshibanami/RedirectWeb/issues)**: バグに遭遇した場合や新機能をリクエストしたい場合は、GitHub Issues ページにアクセスしてください。既存の Issue を閲覧したり、新しい Issue を送信したり、進捗を追跡したりすることができます。
- **[GitHub Discussions](https://github.com/mshibanami/RedirectWeb/discussions)**: 質問がある場合や、開発者や他のユーザーから助けを得たい場合は、GitHub Discussions ページにアクセスしてください。新しいディスカッションを開始したり、既存のディスカッションに参加したりして、コミュニティからサポートを受けることができます。
- **フィードバックフォーム**: RedirectWeb アプリ内のフィードバックフォームからフィードバックを送信できます。これは開発者に直接メールで送信されるため、あなたのフィードバックが他のユーザーに公開されることはありません。

RedirectWeb をご利用いただきありがとうございます！皆様のサポートとフィードバックに感謝いたします。

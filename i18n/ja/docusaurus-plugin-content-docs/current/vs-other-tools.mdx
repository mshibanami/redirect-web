# 他のツールとの比較

いくつかのツールは RedirectWeb と機能が重複しています。RedirectWeb はそれらと連携して動作することを意図しており、このページではそれぞれのツールとの比較を行っています。

> [!NOTE]
> これらの比較は2025年10月時点のものです。古い情報や間違いを見つけた場合は、[お問い合わせ](/contact-us)ください。ありがとうございます！ 🙏

## [Redirector](https://github.com/einaregilsson/Redirector) {/* #redirector */}

Redirector はリダイレクトのための優れたブラウザ拡張機能です。完全に無料でオープンソースであり、Apple以外のプラットフォームでも動作します。しかし、RedirectWeb には気に入っていただけるかもしれないいくつかの追加機能があります：

- ルールに複数の除外パターンや複数の処理一致を設定でき、文字列置換機能は RedirectWeb でのみ利用可能です。
- Mac では、ターゲット URL を開くネイティブアプリを選択できます。RedirectWeb は `open` コマンドを直接呼び出します（ディープリンクではありません）。
- [DNR](https://blog.mozilla.org/addons/2023/05/17/declarativenetrequest-available-in-firefox/) をサポートしており、リダイレクトがより高速になります。
- すべてのブラウザのルールを1か所（ネイティブアプリ）で管理できます。
- Chromium ベースのブラウザでは Manifest V3 を、Firefox では V2 を使用しており、Firefox では Redirector と同じ API を使用できます。
- iOS および macOS の Safari をサポートしています。Redirector はサポートしていません。

私たちは Redirector を深く尊重しており、RedirectWeb は Redirector でも扱える形式でリダイレクトルールをインポートおよびエクスポートできるため、2つのツール間を行き来することができます。詳細は[ルールのインポート・エクスポート](/export-or-import-rules)を参照してください。

## [Tampermonkey](https://www.tampermonkey.net/) や [Greasemonkey](https://www.greasespot.net/) などのユーザースクリプトマネージャー {/* #userscript-managers */}

ユーザースクリプトマネージャーは非常に強力で柔軟です。リダイレクトを含め、非常に多くのことができます。しかし、RedirectWeb と比較するといくつかの欠点があります：

- スクリプトの作成と保守には、特にプログラミングに詳しくない場合、時間がかかります。RedirectWeb では、コーディングなしでルールを作成および管理できます。
- スクリプトは、特に複雑であったり最適化されていない場合、パフォーマンスのオーバーヘッドを引き起こす可能性があり、不用意に作成されたスクリプトは無限リダイレクトループを引き起こす可能性があります。RedirectWeb は効率的かつ安全に動作するよう設計されています。
- 一部のユーザースクリプトマネージャーは、より高速かつ効率的にリダイレクトできる Declarative Net Request (DNR) API にアクセスできない場合があります。RedirectWeb は DNR をサポートしています。

## Apple の[ショートカット](https://support.apple.com/guide/shortcuts/welcome/ios) {/* #why-not-shortcuts */}

ショートカットは iOS および macOS 向けの Apple の自動化ツールです。URL を開くことを含む、多くのタスク向けのショートカットを作成できます。しかし、ショートカットは手動で実行する必要があり、ブラウジング中にページをリダイレクトするようには設計されていません。

## [OpenIn](https://loshadki.app/openin4/) や [Velja](https://sindresorhus.com/velja) {/* #openin-or-velja */}

OpenIn と Velja はどちらもブラウザピッカーアプリであり、ブラウザから別のアプリでリンクを開くことができるブラウザ拡張機能も備えています。RedirectWeb もブラウザからアプリへのリダイレクトが可能ですが、主に2つの点で異なります：

- OpenIn や Velja では、別のアプリでリンクを開くためにツールバーアイコンを選択します。RedirectWeb はルールに基づいて URL を自動的にリダイレクトします。
- OpenIn と Velja は Mac 向けに設計されています。RedirectWeb は Mac 上のすべての主要ブラウザに加えて、iPhone、iPad、Apple Vision Pro の Safari もサポートしています。

## [StopTheMadness](https://underpassapp.com/StopTheMadness/) {/* #stopthemadness */}

StopTheMadness はリダイレクトを含む、ウェブブラウジングを向上させるための多くの機能を備えたブラウザ拡張機能です。しかし、RedirectWeb と比較するといくつかの制限があります：

- ルールの設定オプションが限られています。RedirectWeb は、複数の除外パターンやキャプチャグループ処理など、より詳細なルール設定を備えています。
- リダイレクトのみを行いたい場合には不要かもしれない多くの機能が含まれています。RedirectWeb はリダイレクトのみを行います。
- 12〜15米ドルかかり、無料トライアルや無料プランがありません。RedirectWeb には、基本機能を備えた無料プラン、すべての機能を試せる無料トライアル付きのサブスクリプション、そしてコーヒー1杯分の価格での買い切りオプションがあります。

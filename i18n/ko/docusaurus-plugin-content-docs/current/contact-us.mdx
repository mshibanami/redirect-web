# 문의하기

[FAQ](/faq) 페이지에서 답변을 찾을 수 없는 RedirectWeb에 대한 질문, 피드백 또는 문제가 있는 경우 저희가 도와드리겠습니다.

저희에게 연락하는 가장 좋은 방법은 다음과 같습니다:

- **[GitHub Issues](https://github.com/mshibanami/RedirectWeb/issues)**: 버그를 발견하거나 새로운 기능을 요청하고 싶다면 GitHub Issues 페이지를 방문해 주세요. 기존 이슈를 찾아보거나 새로운 이슈를 제출하고 진행 상황을 추적할 수 있습니다.
- **[GitHub Discussions](https://github.com/mshibanami/RedirectWeb/discussions)**: 궁금한 점이 있거나 개발자 또는 다른 사용자로부터 도움을 받고 싶다면 GitHub Discussions 페이지를 방문해 주세요. 새로운 토론을 시작하거나 기존 토론에 참여하여 커뮤니티의 도움을 받을 수 있습니다.
- **피드백 양식**: RedirectWeb 앱의 피드백 양식을 통해 피드백을 보낼 수 있습니다. 이 양식은 개발자에게 직접 이메일을 보내므로 귀하의 피드백은 다른 사용자에게 공개되지 않습니다.

RedirectWeb을 사용해 주셔서 감사합니다! 귀하의 지원과 피드백에 감사드립니다.

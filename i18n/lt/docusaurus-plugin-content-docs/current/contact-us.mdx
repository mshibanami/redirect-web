# Susisiekite su mumis

Mes esame čia, kad padėtume, jei turite klausimų, atsiliepimų ar problemų dėl RedirectWeb, į kurias neradote atsakymų [DUK](/faq) puslapyje.

Štai geriausi būdai susisiekti:

- **[GitHub Issues](https://github.com/mshibanami/RedirectWeb/issues)**: Jei susidūrėte su klaidomis arba norite paprašyti naujų funkcijų, apsilankykite GitHub Issues puslapyje. Galite naršyti esamas problemas, pateikti naują problemą ir stebėti jos sprendimo eigą.
- **[GitHub Discussions](https://github.com/mshibanami/RedirectWeb/discussions)**: Jei turite klausimų arba norite gauti pagalbos iš kūrėjo ar kitų naudotojų, apsilankykite GitHub Discussions puslapyje. Galite pradėti naują diskusiją, prisijungti prie esamų diskusijų ir gauti pagalbos iš bendruomenės.
- **Atsiliepimų forma**: Galite atsiųsti mums atsiliepimą per atsiliepimų formą RedirectWeb programėlėje. Tai išsiųs el. laišką tiesiogiai kūrėjui, todėl jūsų atsiliepimas išliks privatus ir nebus matomas kitiems naudotojams.

Dėkojame, kad naudojatės RedirectWeb! Vertiname jūsų palaikymą ir atsiliepimus.

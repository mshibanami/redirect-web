# Skontaktuj się z nami

Jesteśmy tutaj, aby pomóc, jeśli masz jakiekolwiek pytania, opinie lub problemy z RedirectWeb, na które nie znalazłeś odpowiedzi na stronie [FAQ](/faq).

Oto najlepsze sposoby na kontakt:

- **[GitHub Issues](https://github.com/mshibanami/RedirectWeb/issues)**: Jeśli napotkasz jakiekolwiek błędy lub chcesz poprosić o nowe funkcje, odwiedź stronę GitHub Issues. Możesz przeglądać istniejące zgłoszenia, przesyłać nowe i śledzić postępy w swojej sprawie.
- **[GitHub Discussions](https://github.com/mshibanami/RedirectWeb/discussions)**: Jeśli masz jakiekolwiek pytania lub chcesz uzyskać pomoc od programisty lub innych użytkowników, odwiedź stronę GitHub Discussions. Możesz rozpocząć nową dyskusję, dołączyć do istniejących i uzyskać pomoc od społeczności.
- **Formularz opinii**: Możesz przesłać nam opinię za pośrednictwem formularza opinii w aplikacji RedirectWeb. Spowoduje to wysłanie wiadomości e-mail bezpośrednio do programisty, dzięki czemu Twoja opinia pozostanie prywatna.

Dziękujemy za korzystanie z RedirectWeb! Doceniamy Twoje wsparcie i opinie.

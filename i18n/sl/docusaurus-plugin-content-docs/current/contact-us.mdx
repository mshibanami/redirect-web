# Kontakt

Tukaj smo, da vam pomagamo, če imate kakršna koli vprašanja, povratne informacije ali težave z RedirectWeb, za katere niste našli odgovorov na strani s [pogostimi vprašanji (FAQ)](/faq).

Tukaj so najboljši načini za stik:

- **[GitHub Issues](https://github.com/mshibanami/RedirectWeb/issues)**: Če naletite na hrošče ali želite zahtevati nove funkcije, obiščite stran GitHub Issues. Lahko brskate po obstoječih težavah, oddate novo težavo in spremljate napredek svoje težave.
- **[GitHub Discussions](https://github.com/mshibanami/RedirectWeb/discussions)**: Če imate kakršna koli vprašanja ali želite dobiti pomoč od razvijalca ali drugih uporabnikov, obiščite stran GitHub Discussions. Lahko začnete novo razpravo, se pridružite obstoječim razpravam in dobite pomoč skupnosti.
- **Obrazec za povratne informacije**: Povratne informacije nam lahko pošljete prek obrazca za povratne informacije v aplikaciji RedirectWeb. To bo poslalo e-pošto neposredno razvijalcu, tako da bodo vaše povratne informacije ostale zasebne pred drugimi uporabniki.

Hvala, ker uporabljate RedirectWeb! Cenimo vašo podporo in povratne informacije.

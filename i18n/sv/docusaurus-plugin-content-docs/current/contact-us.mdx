# Kontakta oss

Vi finns här för att hjälpa till om du har frågor, feedback eller problem med RedirectWeb som du inte hittat svar på på [FAQ](/faq)-sidan.

Här är de bästa sätten att komma i kontakt:

- **[GitHub Issues](https://github.com/mshibanami/RedirectWeb/issues)**: Om du stöter på buggar eller vill begära nya funktioner, besök sidan för GitHub Issues. Du kan bläddra bland befintliga ärenden, skicka in ett nytt ärende och följa utvecklingen av ditt ärende.
- **[GitHub Discussions](https://github.com/mshibanami/RedirectWeb/discussions)**: Om du har frågor eller vill få hjälp av utvecklaren eller andra användare, besök sidan för GitHub Discussions. Du kan starta en ny diskussion, delta i befintliga diskussioner och få hjälp från communityn.
- **Feedbackformulär**: Du kan skicka feedback till oss via feedbackformuläret i RedirectWeb-appen. Detta skickar ett e-postmeddelande direkt till utvecklaren, så din feedback hålls privat för andra användare.

Tack för att du använder RedirectWeb! Vi uppskattar ditt stöd och din feedback.

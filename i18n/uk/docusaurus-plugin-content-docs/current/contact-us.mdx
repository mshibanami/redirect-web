# Зв'яжіться з нами

Ми тут, щоб допомогти, якщо у вас є будь-які запитання, відгуки або проблеми з RedirectWeb, відповіді на які ви не змогли знайти на сторінці [FAQ](/faq).

Ось найкращі способи зв'язатися з нами:

- **[GitHub Issues](https://github.com/mshibanami/RedirectWeb/issues)**: Якщо ви зіткнулися з будь-якими помилками або хочете запропонувати нові функції, будь ласка, відвідайте сторінку GitHub Issues. Ви можете переглянути наявні проблеми, надіслати нову та відстежувати прогрес її вирішення.
- **[GitHub Discussions](https://github.com/mshibanami/RedirectWeb/discussions)**: Якщо у вас є запитання або ви хочете отримати допомогу від розробника чи інших користувачів, будь ласка, відвідайте сторінку GitHub Discussions. Ви можете почати нове обговорення, приєднатися до наявних та отримати допомогу від спільноти.
- **Форма зворотного зв'язку**: Ви можете надіслати нам свій відгук через форму зворотного зв'язку в застосунку RedirectWeb. Це надішле електронний лист безпосередньо розробнику, тому ваші відгуки залишаться приватними для інших користувачів.

Дякуємо, що користуєтеся RedirectWeb! Ми цінуємо вашу підтримку та відгуки.

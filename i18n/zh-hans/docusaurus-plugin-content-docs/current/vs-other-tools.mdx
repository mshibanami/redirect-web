# 与其他工具的比较

有几个工具与 RedirectWeb 的功能有所重叠。RedirectWeb 旨在与它们协同工作，本页将它与各个工具进行对比。

> [!NOTE]
> 这些比较基于 2025 年 10 月的状态。如果您发现任何过时信息或错误，请[联系我们](/contact-us)。谢谢！🙏

## [Redirector](https://github.com/einaregilsson/Redirector) {/* #redirector */}

Redirector 是一个很棒的浏览器重定向扩展。它完全免费且开源，并且也适用于非 Apple 平台。但 RedirectWeb 还有一些您可能会喜欢的功能：

- 规则可以包含多个排除模式和多个处理匹配，并且字符串替换功能仅在 RedirectWeb 中可用。
- 在 Mac 上，您可以选择由哪个原生应用打开目标 URL。RedirectWeb 直接调用 `open` 命令（而不是深度链接）。
- 它支持 [DNR](https://blog.mozilla.org/addons/2023/05/17/declarativenetrequest-available-in-firefox/)，这让重定向速度更快。
- 您可以在原生应用这一个地方统一管理所有浏览器的规则。
- 它在基于 Chromium 的浏览器上使用 Manifest V3，在 Firefox 上使用 V2（在此可以使用与 Redirector 相同的 API）。
- 它支持 iOS 和 macOS 上的 Safari。Redirector 则不支持。

我们非常尊重 Redirector，RedirectWeb 可以按照 Redirector 同样支持的格式导入和导出重定向规则，因此您可以在两者之间进行切换。详情请参阅[导出或导入规则](/export-or-import-rules)。

## 像 [Tampermonkey](https://www.tampermonkey.net/) 或 [Greasemonkey](https://www.greasespot.net/) 这样的用户脚本管理器 {/* #userscript-managers */}

用户脚本管理器非常强大且灵活。您可以用它们做很多事情，包括重定向。但是，与 RedirectWeb 相比，它们有一些缺点：

- 编写和维护脚本需要花费时间，尤其是如果您不熟悉编程的话。RedirectWeb 让您无需编写代码即可创建和管理规则。
- 脚本可能会带来性能开销，特别是当它们较为复杂或未经过优化时；编写不当的脚本还可能导致无限重定向循环。RedirectWeb 旨在做到高效且安全。
- 某些用户脚本管理器可能无法使用 Declarative Net Request (DNR) API，而该 API 重定向速度更快且更高效。RedirectWeb 支持 DNR。

## Apple 的 [快捷指令](https://support.apple.com/guide/shortcuts/welcome/ios) {/* #why-not-shortcuts */}

快捷指令是 Apple 为 iOS 和 macOS 提供的自动化工具。您可以为许多任务创建快捷指令，包括打开 URL。但是，您必须手动触发快捷指令，并且快捷指令并不是为了在您浏览网页时重定向页面而设计的。

## [OpenIn](https://loshadki.app/openin4/) 或 [Velja](https://sindresorhus.com/velja) {/* #openin-or-velja */}

OpenIn 和 Velja 都是浏览器选择器应用，它们也提供浏览器扩展，让您可以从浏览器在另一个应用中打开链接。RedirectWeb 也可以从浏览器重定向到应用，但两者在两个方面有所不同：

- 使用 OpenIn 和 Velja 时，您需要点击它们的工具栏图标才能在另一个应用中打开链接。RedirectWeb 则会根据您的规则自动重定向 URL。
- OpenIn 和 Velja 是专为 Mac 设计的。RedirectWeb 支持 Mac 上的所有主流浏览器，以及 iPhone、iPad 和 Apple Vision Pro 上的 Safari。

## [StopTheMadness](https://underpassapp.com/StopTheMadness/) {/* #stopthemadness */}

StopTheMadness 是一个具有许多用于改善网页浏览体验功能的浏览器扩展，其中包括重定向。但是，与 RedirectWeb 相比，它有一些局限性：

- 它的规则配置选项较为有限。RedirectWeb 具有更详细的规则设置，包括多个排除模式和捕获组处理。
- 它包含很多功能，如果您只需要重定向，这些功能可能用不上。RedirectWeb 仅专注于重定向。
- 它的售价为 12–15 美元，没有免费试用或免费方案。RedirectWeb 提供具有基本功能的免费方案、可免费试用所有功能的订阅方案，以及仅需一杯咖啡价格的一次性购买选项。

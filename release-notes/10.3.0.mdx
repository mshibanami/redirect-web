- [iOS] Added Liquid Glass support.
- Redesigned Quick Look previews for `.redirectweb` files.
- Fixed an issue where `.redirectweb` files exported from RedirectWeb Pro could not be imported.
- Fixed an issue where paused rules were unexpectedly resumed after restarting the device.
- [MDM] Fixed an issue where enforced rules were not correctly reflected in RedirectWeb Pro.
- Other minor bug fixes and performance improvements.

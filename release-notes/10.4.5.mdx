- **FIXED** Reduced the app size (Mac: 65.7 MB → 29.6 MB / iOS: 40.3 MB → 22.9 MB)
  - Since RedirectWeb 10.3.0, the app size has increased a lot. This was caused by a dependency that we use to verify purchases. It introduced additional dependencies to improve portability, and that's the main cause of this issue. For now, we've downgraded it to a stable version.
  - Removed many unused or redundant translations.
  - Removed unused code.
